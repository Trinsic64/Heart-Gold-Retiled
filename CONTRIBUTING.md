# Contributing

Feedback and mapping help are welcome while Pokémon HeartGold Retiled remains unfinished.

## Reporting visual problems

Please open one issue per location or closely related group of locations. Include:

- the in-game location and nearest landmark;
- the patch version;
- a short description of the problem;
- steps needed to reach or reproduce it; and
- screenshots that show the affected tiles, if available.

Do not upload a ROM, extracted ROM files, a DSPRE workspace, or copyrighted game data that is not already present in this repository.

## Proposing map changes

Keep pull requests focused and explain which map or tiles were changed. When possible, include before/after screenshots and list the relevant files.

Before submitting:

1. Confirm no `.nds`, `.srl`, save, executable, DSPRE, or extracted-ROM files are included.
2. Confirm the change opens correctly in the mapping tool you used.
3. Test the affected area in game using your own legally obtained ROM.
4. Review `git diff --stat` and the staged file list for accidental additions.

The automated content-safety workflow catches common prohibited file types and oversized files, but it is not a substitute for reviewing your contribution.

## Rights and attribution

Only contribute material you have the right to share. By contributing, you confirm that your contribution may be stored and publicly distributed as part of this repository. No broader license is implied for third-party game assets.
