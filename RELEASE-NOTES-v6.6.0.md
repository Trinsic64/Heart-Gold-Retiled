# HeartGold Retiled Expansion v6.6.0

This work-in-progress prerelease adds the HG-Engine gameplay expansion to HeartGold Retiled and publishes a complete first set of player guides.

## Download

- **Patch:** `HG-Retiled-Expansion-Patch.xdelta`
- **Size:** 35.7 MiB (37,401,812 bytes)
- **SHA-256:** `5D1CB8B8721316AEDFD45BB8564EF428DE4E856FC4AEFFCEE7B53F22D4DDCA4D`

Apply this patch to a clean, legally obtained **Pokémon HeartGold (USA)** ROM matching the hashes in the repository README. Apply only this patch; do not stack it with the visual-only Retiled patch.

## Expansion highlights

- Generation 9 rules baseline, Fairy type, expanded Pokémon/move/item data, and redesigned encounters and trainer teams
- Mega Ring awarded with the Pokédex and all 92 Mega Stones distributed as visible pickups
- Mega-family wild held-item sources, Primal Orb sources, and a version-neutral Embedded Tower path
- Offline Celebi, shiny Pichu, Arceus, Shaymin, Diancie, and Enigma Stone access using the original event continuations
- Full walkthrough, evolution, HG-Engine feature, encounter, item, and trainer documentation

## Work-in-progress warnings

- The project remains a prerelease and may contain map/tile issues or gameplay bugs.
- The expansion patch header and checksum were validated, but a clean-ROM apply and full runtime playthrough could not be performed in this repository-only release session.
- A heavily populated Items pocket approaching 290 distinct entries still needs emulator stress testing. Keep rotating save backups while collecting all stones.
- Z-Moves, Dynamax/Gigantamax, Terastallization, discontinued online services, Pal Park replacement, and Pokéwalker replacement are not included.

No ROM is included. This release contains only a binary difference patch and documentation.
